# Default — Publishing Guide (for Repurposed Content)

**Type:** Generic fallback used when a site returned by the sites API doesn't have its
own dedicated guide in this folder yet. Add a `{site-id}.md` file here (same id shown in
the Sites dropdown) to override this for any specific site — no code change needed.

**Repurposing verdict:** ⚠️ **Assume no canonical-link support and treat this as a
backlink/reach channel, not a syndication mirror**, unless you know otherwise. Rework the
source article into a genuinely distinct version rather than a verbatim copy, and include
a contextual link back to the original article near the top or in an author bio/footer.

**Tone & structure:**
- Keep the core topic, factual claims, and data points from the source article intact — never invent statistics, quotes, or URLs that aren't in the source.
- Match a neutral, professional blog-post tone unless the platform is obviously informal (a personal blog, a creator-support platform, etc.).
- Standard structure: a short intro hook, 3-6 body sections with clear subheadings, a brief conclusion, and a one-line attribution back to the source article.
- Length: roughly the same length as the source article unless the platform is clearly short-form (e.g. a microblog) — when in doubt, match the source.
- No fabricated author credentials, testimonials, or brand claims beyond what the source/brand context supports.
