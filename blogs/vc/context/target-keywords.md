## Usage Guidelines

### Writing a New Article
1. **If primary and secondary keywords are provided with the article topic, use those as-is** — the provided primary keyword is the focus keyword and the provided secondary keywords must all be covered (each at least 5 times)
2. In addition to the provided keywords, check this file for any relevant keywords from the matching cluster and incorporate them naturally into the article
3. If no keywords are provided, identify which cluster the article topic belongs to and choose the most relevant keyword from that cluster as the focus keyword
4. Add focus keyword to SEO title, meta description, URL slug, and first 100 words
5. Link to the cluster's target URL at least once using a natural anchor

### Avoiding Keyword Cannibalization
Do not write two separate articles targeting the same primary focus keyword. If a keyword is already covered in a published article, reference it with an internal link rather than creating a new article on the same topic.

### Quarterly Review
Update this file when new service pages are added, keyword volumes shift significantly, or new target pages are identified.
