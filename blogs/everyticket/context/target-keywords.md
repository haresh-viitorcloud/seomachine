## Keyword Cannibalization Watch

These keyword pairs are closely related and risk competing across multiple articles. Monitor and differentiate content angles:

| Keyword A | Keyword B | Risk Level | Action |
|---|---|---|---|
| online ticketing solutions | online ticketing service | Medium | Different content angle (solution = platform; service = provider) |
| digital ticketing system | digital ticketing solutions | Medium | System = tech; Solutions = broader outcome focus |
| museum ticketing software | ticketing software for museums | Low | Same keyword, different word order — use as variations on one page |
| event ticketing software | ticketing software for events | Low | Use as variations, not separate articles |
| white label ticketing platform | white label ticketing platform | Duplicate in source file | One article, not two |
| museum ticketing software | museum ticketing system | Low | Software = product; System = capability — can be one article or separate with distinct angles |

## Usage Guidelines

### When Writing a New Article
1. Check which cluster the topic belongs to
2. Confirm no existing published article already targets the same keyword (check everyticket.in/blog)
3. Use the pillar keyword + 2–3 cluster keywords as primary targets
4. Each target keyword must appear at least 4 times (per seo-guidelines.md)
5. Include relevant LSI/semantic terms naturally throughout
6. Link to the pillar article from cluster articles and vice versa

### When Optimising Existing Content
1. Verify the page targets the correct cluster keyword
2. Check for cannibalization against the table above
3. Ensure all target keywords appear at least 4 times
4. Add internal links to/from related cluster articles
5. Update the Current Ranking field below from GSC data

### When Planning the Content Calendar
1. Work down the High Priority pipeline first
2. Build out each cluster systematically (pillar first, then cluster articles)
3. Avoid creating two articles that target the same keyword — check this file before briefing
