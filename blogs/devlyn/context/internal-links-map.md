# Devlyn Internal Links Map

This document is the definitive reference for internal linking when writing any Devlyn content. Always reference this alongside devlyn-content-map.md and devlyn-seo-guidelines.md.

Minimum 3 internal links per blog post. Optimal: 4–6. All anchor text must be descriptive — never "click here" or "read more".

---

## Core Pages (Always Available to Link To)

### Homepage
- **URL**: https://devlyn.ai
- **When to Link**: Rarely — only when introducing Devlyn as a company for the first time in a piece
- **Anchor Text Examples**: "Devlyn", "Devlyn's engineering team", "Devlyn.ai"

### Primary CTA / Contact
- **URL**: https://devlyn.ai/contact
- **When to Link**: Every post — always at the end with CTA, optionally mid-article in solution posts
- **Anchor Text Examples**: "Book a Strategy Call", "Talk to an Engineering Lead", "schedule a strategy call", "reach out to Devlyn's engineering team"
- **Note**: This is the ONLY CTA destination. Never link to a different contact URL.

## What NEVER to Do

- Never link to competitor websites (Bacancy, Acquaintsoft, ValueCoders, MoonTech, Appinventiv)
- Never use "click here", "read more", "learn more", "here", "this article" as anchor text
- Never link to devlyn.ai/long-form-content or devlyn.ai/page-not-found (deprecated pages)
- Never add more than 8 internal links in a standard post (it dilutes signals)
- Never link to the same URL twice with different anchor text in the same post unless unavoidable
