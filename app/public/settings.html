Admin Credentials

🔒

Admin username and password are managed via the .env file.

The server syncs credentials from .env on every restart — any change made here would be overwritten. To update your password:

  1. Edit .env and update ADMIN_PASSWORD=your_new_password
  2. Restart the server — the new password takes effect immediately
